Features

Everything follows your cursor.

Keyboard, mouse, clipboard and sound move together, so several PCs feel like one big desk.

Instant

Mouse moves go straight from the input hook onto the network, with no queues in the way.

~14 µs per move, measured on loopback

Smooth under load

Priority-tagged traffic, a Wi-Fi keepalive and duplicated keystrokes keep it responsive while torrents and downloads run.

Shared clipboard

Copy on one PC, paste on another. Text travels with the cursor automatically.

Audio both ways

Hear any PC on your headphones, and send your microphone to another PC, with the sending PC muted.

Encrypted

Every keystroke is sealed with ChaCha20-Poly1305, with fresh keys for each session.

Updates itself

New versions install quietly when you're not mid-task. Each one is signature-checked first.

How it works

Set up in under a minute.

Host on your main PC

Install glide on the PC with the keyboard and mouse, and choose Host. It shows a connection code.

Connect the others

On each other PC, choose Connect. Nearby hosts appear automatically: paste the code once.

Arrange and glide

Place each screen left, right, above or below, then move the cursor across. Ctrl+Alt+Esc brings it home.

Built for speed

No lag. Even with a torrent running.

  • Native Rust, with no runtime or background bloat.
  • UDP fast path for movement. Keys are sent twice plus a reliable backup, so a dropped packet never stalls you.
  • Priority packets that routers and Wi-Fi send first, ahead of bulk downloads.
  • Lives in the tray and starts with Windows if you like.

FAQ

Questions

Is it really free?

Yes. glide is open source under the MIT license, with no accounts, no telemetry and no subscription.

Does it work over the internet?

glide is built for PCs on the same local network (home or office Wi-Fi or Ethernet). For other locations, put both PCs on the same VPN.

What about Mac and Linux?

Windows 10 and 11 are supported today. A macOS version is in the source as a preview: build it on a Mac with cargo build --release. Linux isn't supported yet.

Is my typing safe on the network?

Everything is encrypted and authenticated with ChaCha20-Poly1305, using keys derived from a secret only your devices know. The connection code contains that secret, so share it only with your own PCs. If a code leaks, press New code.

Windows says the app is unrecognised

glide isn't code-signed yet, so SmartScreen may warn on first run. Choose More info → Run anyway. Updates themselves are verified with glide's own release signature before installing.

Can I hear another PC through my headphones?

Yes. On the host, turn on Hear the remote here, and on the other PC turn on Send to the host with This PC's sound. That PC goes quiet while its sound plays on your headphones.
